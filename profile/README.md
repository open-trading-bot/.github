# open-trading-bot

An open-source algorithmic crypto trading bot for [Bybit](https://www.bybit.com).

The bot has three parts:

- **Server:** the API and the trading engine. The engine runs the strategies at a fixed interval.
- **Dashboard:** users see positions, strategies and backtests.
- **Backoffice:** admins manage users, roles, invitations and feature flags.

## Start here

1. Read the [README](https://github.com/open-trading-bot/open-trading-bot#readme) of the main repository.
2. Start the bot in **paper mode** or on the **Bybit testnet**.
3. Use live mode only when you understand the risk.

> **Disclaimer:** This software is **not financial advice**. Crypto trading has a high risk of loss. You use this software at your own risk.
